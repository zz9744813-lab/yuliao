# 源文本策略 + SFT 小规模验证 Runbook（2026-09-19，授权项 2/4 的 P2 补充）

## 一、源文本策略（P2-8，军师方向：优先找干净版本）

**定性修正**：字表归一化（`scripts/normalize_typos.py`）只是**局部修补**——
修好 347 段人名 ≠ 语料修好了。盗版 txt 的损伤是家族性的：
单字替换（千雪/吴天）只是其中一类，缺句、截断、上下文乱码
（将夜的"化柞""脏老逛"）都修不掉，只能靠 LLM 校勘逐段兜。

**策略（按优先级）**：
1. **找更干净的源**：琼明已有精校版（0.26% 污染）就是证据——将夜/凡人/斗罗
   各找一版精校/正版对照，抽 50 段比对即可验证干净度。找到后：
2. **换源必须新建版本**：新 Work（title 带版本后缀）+ 重新切分（seg_version+1）
   + 重新绑定帧/标注/劣化。旧 Work 冻结只读——已建基准集已冻结文本，不受影响；
3. LLM 校勘（source_check）与字表归一化只作为**找不到干净源时的兜底**。

**验证协议（找源时用）**：随机抽 50 段新旧对照，数差异处；新源差异 < 0.5%
即认为显著更干净。**约束：不下载大文件到本机仓库**——下载放 data/inbox/
之外的位置，入库只收通过抽检后的文本。

## 二、SFT 小规模验证 Runbook（P2-9：数百条先跑通管线）

**目标**：不等 100K 帧，先用现有数据验证「训练→评测」闭环可跑、方向可测。
**前置确认（需集霸/军师点头，本轮不执行）**：租卡账号与预算（预估 ¥10~35/迭代）。

1. **数据**（全部走新口径导出，含内容级隔离）：
   - `writer_sft_v4.jsonl`：合格子集（src_ok=True + 无未校验段）；
   - 抽 **300~500 条**（跨 4 作品分层）作为验证集——不是越大越好，第一轮只验管线；
2. **训练**（租 4090，2~3 小时）：
   - 基座：Qwen2.5-7B-Instruct（或当下最新 7B 中文基座）；
   - QLoRA r=16 / alpha=32 / 目标模块 q,k,v,o,gate,up,down；lr 1e-4；3 epochs；
   - 框架：llamafactory 或 unsloth（任一，脚本级差异）；
3. **评测（训前基线与训后各跑一次）**：
   - `nat-v1` / `hvai-v1` / `cc-v1` 三读数（benchmark_run.py --models <本地推理>)；
   - **主从端点先定死（防挑最好看）**：主端点 = nat-v1；hvai-v1 / cc-v1 为
     次要端点只报告不参与"方向成立"判定。最小效应量：主端点 ≥ +0.03 且
     过 falsify 全套（含长度基线——**训后模型必须同时压过长度基线**）；
     次要端点无论多好看，单独不构成方向成立的依据；
   - **推理配置与训练锁定为同一套**（否则训前训后读数不同源，整轮作废）：
     chat template（用训练侧导出适配器时一并导出 tokenizer/template 配置）、
     截断长度（与训练 max_seq_len 一致）、精度（与评测时一致，训前基线也用
     同一 GGUF 量化档）、temperature=0 与基准判分口径一致；四项写进迭代记录；
   - 推理：本地 Ollama/vLLM 加载 LoRA 导出 GGUF；
4. **判读**（provisional）：
   - **方向成立 = 主端点（nat-v1）≥ +0.03 且过 falsify 全套**（次要端点只在
     主端点达标后作辅助解读）→ 再谈集霸人工盲评 30 题；
   - 主端点不达标 → 检查数据配比（SFT 过拟合人类原文 vs 目标"拦 AI 味"的错位，
     此时 ai_ranking/负面库的 DPO 才是主力）；
5. **记录**：每次迭代把读数 + falsify 报告 + 配置 hash 写进
   `docs/training-iterations-<日期>.md`，可复现优先。

**失败模式预案**：
- 训后更 AI 味 → SFT 目标（模仿人类原文）与判据（去 AI 味）错位 → 转 DPO 主力；
- 灾难遗忘（通用能力掉）→ 降 epoch / 加通用语料回放；
- 读数波动超效应 → falsify 的置换检验会拦，别急着宣布成功。
