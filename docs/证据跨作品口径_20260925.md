# K3 证据「跨作品」口径（2026-09-25）

## 1. 现状与问题

`docs/K2解锁仿真_20260925.md` §3.4 的真库只读实跑已经证明：原
`_evidence_for(s, strategy_id, policy)` 只按 `strategy_id` 取 verified 实例，
不按 `policy.book_id` 绑定证据来源。给覆汉 `WK-dc90993434e9` 授予
`scope=WORK` 后，查询层会把琼明神女录 `WK-6e5d2623` 的唯一一条非基准证据
作为覆汉的包内容。因此，「策略授予给哪本作品」与「证据实际来自哪本作品」
可以不一致，而原响应没有字段披露这种不一致。

本次改动**不静默改默认选择结果**：默认仍允许既有跨作品证据，但每个选中策略
都如实报告它。`S0` 仍为 `selected=0`，既有 S3 仿真仍为 `selected=1`；覆汉
S3 的该条选择会显示 `evidence_cross_work=true`，而不是继续把跨作品证据描述成
覆汉原生证据。

## 2. 如实报告字段

`query_knowledge` 的每个 `selected[]` 策略条目新增：

| 字段 | 类型 | 口径 |
|---|---|---|
| `evidence_cross_work` | `bool` | 查询作品有登记行，且该策略最终选中证据中**至少一个** canonical 根作品不同于查询作品的 canonical 根作品时为 `true`；否则为 `false`。 |
| `evidence_root_works` | `list[str]` | 该策略最终选中证据的 canonical 根作品 id，去重后按字典序排序。 |
| `evidence_cross_work_note` | `str`，条件出现 | 查询作品查不到 `WorkSource` 登记行时出现。此时按「不判 cross」返回 `evidence_cross_work=false`，并明确说明未完成判定。 |

查询作品的根作品必须通过 `WorkSource(work_id=policy.book_id)` 登记行解析
`canonical_work_id`，不能把 `policy.book_id` 字面当作根作品 id。证据根作品则
沿用 `_evidence_for` 已有的登记行解析及镜像聚合口径。因此：

- 根作品与登记为同一 canonical 根的镜像都属于同根，跨作品为 `false`；
- 同根与异根证据并存时，只要存在一个异根，跨作品即为 `true`；
- 缺查询作品登记行时，不从其他行猜根作品，也不把“未知”冒充 `false` 之外的
  已判定事实；响应通过 note 明示。

这两个报告字段只描述已经通过既有硬门和可选收窄门、实际进入该策略条目的
证据，不改变 `selected_ids`、策略排序或 `score_components.evidence_count`。
字段定义与开关默认值也写入 `/knowledge/capabilities` 的
`evidence_provenance` 结构说明。

## 3. 可收窄开关

调用方可在 `source_policy` 中设置：

```json
{
  "source_policy": {
    "require_same_book_evidence": true
  }
}
```

语义如下：

1. **默认关闭**：字段缺省或为 `false` 时，不增加作品来源过滤，保持既有选择结果。
2. **只收窄、不放宽**：为 `true` 时，先经登记行取得查询作品的 canonical 根，
   再只保留 canonical 根与它相同的证据。异根证据在既有 benchmark、
   `excluded_source_type`、`excluded_use`、`text_version`、mirror dedup 五道门
   之后收窄，不能绕过或放宽任何一道既有硬拦。
3. **缺登记行从严**：查询作品没有 `WorkSource` 登记行时，无法证明证据同根；
   开关开启后不保留证据。默认关闭时仍按第 2 节返回“不判 cross”及 note。
4. **镜像仍按根作品同源**：同根镜像可保留，继续参与既有
   `(canonical_work_id, span_start, span_end)` 去重；不把镜像误报为跨作品。

覆汉场景只有琼明的非基准证据，开关关闭时仍能选中 1 条并报告
`evidence_cross_work=true`；开关开启后该异根证据被剔，`selected=0`。这是
调用方主动选择更严口径的结果，不是默认行为变化。

## 4. 对拍板的影响：选项与代价

证据是否必须与被授予作品同源，属于**集霸裁定范围**。本实现只提供可观测事实和
可收窄选项，不替集霸下结论。可供拍板的选项及代价是：

| 选项 | 收益 | 代价 |
|---|---|---|
| 保持默认关闭，只要求调用方读取 `evidence_cross_work` | 保持现有包数量与兼容性；跨作品不再不可见 | 允许调用方忽略告警后继续使用异根证据；覆汉 S3 仍显示 1 条选择，但该条依赖琼明证据 |
| 对相关调用强制 `require_same_book_evidence=true` | 包内证据与目标作品 canonical 根一致，来源边界更窄、更易审计 | 覆汉因无原生合格证据降为 `selected=0`；需要补抽覆汉证据才能恢复覆盖 |
| 按场景逐次选择开关 | 同一机制可兼顾存量兼容与需要原生证据的场景 | 调用方必须把该字段纳入 policy 并承担选择责任；漏传时仍是默认关闭口径 |

无论选择哪项，当前响应都已能区分“结构上选中了策略”和“证据是否跨作品”；不拍板
也不等于继续把两者混为一谈。
