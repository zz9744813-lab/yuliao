## 1. 三卡口径（实现原文）

新增常量（`scripts/clean_text.py`，紧跟既有 `GUARD_MIN_RATIO`，命名/注释风格与既有 `GUARD_*` 一致）：

```python
GUARD_MAX_RATIO = 1.2    # 相对长度上限：out > 1.2×src → 视为"原文 + 垃圾追加"，拒
GUARD_MIN_SIMILARITY = 0.6  # 相似卡：SequenceMatcher(None, src, out).ratio() 低于此 → 视为跑题改写
GUARD_MAX_LATIN_RATIO = 0.3 # 拉丁占比卡：out 里 [A-Za-z] 占比 > 此 而 src 不 > 此 → 视为无声调拼音化
```

判定链（`guard_verdict`，**既有四态的语义与顺序一字未改**，三张新卡一律排在 `truncated` 之后、`accept` 之前）：

```python
    s_src, s_out = (src or "").strip(), (out or "").strip()
    if s_out == s_src:
        return "identical"
    if len(s_out) < GUARD_MIN_LEN:
        return "too_short"
    if len(s_src) > GUARD_SHORT_SRC:
        n_src, n_out = len(s_src), len(s_out)
        if n_out < GUARD_MIN_RATIO * n_src:
            return "truncated"
        if (_latin_ratio(s_out) > GUARD_MAX_LATIN_RATIO
                and _latin_ratio(s_src) <= GUARD_MAX_LATIN_RATIO):
            return "latinized"
        if n_out > GUARD_MAX_RATIO * n_src:
            return "oversize"
        if SequenceMatcher(None, s_src, s_out).ratio() < GUARD_MIN_SIMILARITY:
            return "divergent"
    return "accept"
```

辅助函数：

```python
def _latin_ratio(text: str) -> float:
    """拉丁字母（A-Za-z）占字符数比例；空串返回 0.0。"""
    return len(_LATIN_CHAR.findall(text)) / len(text) if text else 0.0
```

实跑常量值（本会话读取模块所得，非文档抄写）：
`GUARD_MIN_LEN=20`、`GUARD_MIN_RATIO=0.6`、`GUARD_MAX_RATIO=1.2`、`GUARD_MIN_SIMILARITY=0.6`、
`GUARD_MAX_LATIN_RATIO=0.3`、`GUARD_SHORT_SRC=40`。

**落库面**：`run_llm` 的写入分支保持 `if verdict != "accept": 计 llm_rejected → continue`
——三个新增态天然非 `accept`，因此**不落库**，无需改写入逻辑（只把那行行尾注释补成
「过短/截断/拼音化/超长/跑题 → 保留原值不写」）。`GUARD_ENV`（`CLEAN_TEXT_GUARD=0/off/false/no`）
关后门照旧整体失效。`guard_verdict` 全仓消费方只有 `scripts/clean_text.py::run_llm` 与
`tests/test_clean_text_guard.py`（本会话 grep 核实：排除这两处后命中 0 行）。

**新卡内部顺序 `latinized → oversize → divergent` 的理由**：整段拼音化必然同时拉长文本、
拉低相似度，若把拉丁卡排在后面，同一污染会被笼统记成 `oversize`/`divergent`——
拒绝是对的，但 `_stat["llm_rejected"]` 的归因失真，运维看不出"拼音化"这一类还在发生。
先判拉丁占比可给出贴病灶的态名。该顺序**不影响任何拒绝结果**（三卡任一命中都是非 `accept`）。

**短原文豁免（与既有口径一致）**：三张新卡与 `truncated` 同享
`len(s_src) > GUARD_SHORT_SRC`（40）这道闸——`src` 去空白后 ≤ 40 字时全部比例类/相似度类判定一并跳过，
只保留绝对下限 `GUARD_MIN_LEN`。理由（已写进常量注释）：短段分母小，"合理改写"天然会动掉大半字符，
长度比、`SequenceMatcher` 相似度、拉丁占比在小分母下全都失真；而**误杀是整段拒绝落库**
（好正文永远修不掉，且 `still_broken` 也统计不到它），代价高于漏判。
既有 `test_short_src_exempt_from_ratio` 未改一行即通过，正是这条豁免生效的证据
（其 `out` 与 `src` 相似度远低于 0.6，若新卡不吃豁免必判 `divergent` 而转红）。

## 3. 阈值取值理由（两侧余量为本会话实跑）

| 常量 | 取值 | 理由（实测两侧余量） |
|---|---|---|
| `GUARD_MAX_RATIO` | **1.2** | 任务/原审同值。合法修复不会变长（拼音→汉字通常**缩短**：实测 len_ratio 0.9333；剥水印后 0.6437），反例 (b) 为 4.4000；1.2 给到"必要重写 + 少量补字"的容忍，同时离污染侧很远。严格 `>` 比较，边界用例见 §5/§6（49 字放行 / 50 字 `oversize`）。 |
| `GUARD_MIN_SIMILARITY` | **0.6** | 原审建议值。**合法侧实测**：拼音还原 0.9310、剥水印+还原 0.7552、"原文 + 13 位数字尾巴"0.9023；**污染侧实测**：跑题段 0.0496、全拼音化 0.0000。两侧各自至少留 0.15 以上余量，0.6 居中。 |
| `GUARD_MAX_LATIN_RATIO` | **0.3** | 原审建议值。中文小说正文拉丁占比通常 <10%（`SRC` 这种带拼音的脏原文也只有 0.0667，剥水印原文 0.0920），拼音化会推到 0.7368。取 0.3 让合法侧留 ≥2×、污染侧 ≥2×。**src 自己就 >0.3 时本卡保持沉默**：那是"本来就大段拉丁"，不是"原文中文→结果拼音化"，误杀代价高于漏判。 |
| `GUARD_SHORT_SRC` | **40（未改）** | 沿用既有豁免口径，新卡不吃这条豁免就会误杀正常短段修复。 |

已知副作用（如实登记，非新缺陷）：`llm_rejected` 的含义从「过短/截断」扩为「过短/截断/拼音化/超长/跑题」，

边界悬崖（`src` 去空白 40→41 字时判定翻转）为原审已声明的设计内取舍，本次未改动、也未加宽。

## 5. 承重与**反向验证**（逐卡摘卡 ⇒ 必转红 ⇒ 恢复必复绿，含 md5 一致证据）

三轮均输出 `MUTATION_ISOLATED_OK` ⇒ 变异面确实只有该卡一行。
每轮：应用变异 → 跑 C3 同一条验收命令 → 记录红项 → `cp` 回树外 pristine → 校 md5 → 复跑验收。
