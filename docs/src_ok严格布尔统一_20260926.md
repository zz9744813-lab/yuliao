## 1. 唯一入口（`scripts/k2_extract_backfill.py` L103-143）

判定层四级收敛，全部为**纯函数、绝不抛异常**的 fail-closed 严格布尔：

| 函数 | 语义 |
|---|---|
| `integrity_dict(seg_or_value)` | integrity 原文 → dict 的唯一安全解析层：带 `.integrity` 属性的对象取其属性；已是 dict 直接用；解析失败 / 空值 / **合法 JSON 非字典** 一律 → `{}` |
| `integrity_flag_state(seg_or_value, key)` | 通用 flag 三态：JSON `true`→`True`，JSON `false`→`False`，其余（缺键/`"false"`/`1`/`0`/`null`/非字典/解析失败）→ `None` = **未校验** |
| `src_ok_state(seg_or_value)` | = `integrity_flag_state(x, "src_ok")`，与写入侧 `source_check.parse_src_ok` 同语义的读取镜像 |
| `src_ok_strict(seg_or_value)` | **源检查闸唯一读取入口**：`src_ok` 必须是 JSON 布尔 true 才过闸；未校验一律 `False`（不过闸） |

`_src_ok(seg)` 保留为 `src_ok_strict(seg)` 的兼容薄包装（k2 内部 L205 调用点不变）。
