## 3. 判定与必须随行的注记

- **档一（方向识别，预注册达标线 ≥0.80）：2/3 评委过线（qoder、kimi），agnes 未达**。
  按预注册口径为**方向识别能力成立**的正面结论——不再为把 agnes 拉过线而加新代实验（K0 明令）。
- **类型混杂（必读注记）**：L 侧全部由 LITERARY_OVERWRITE + SUBTEXT_ERASE
  两型构成、S 侧为旧代多型——S/L 对照带类型与实验代际混杂，**每类型分层读数未做**
  （需类型子基准扩展，显式标注为未完成子检验，不以本报告读数推断单类型可分性）。
- **档二（复现人类口味）**：与本集无关的否定性结论维持原状（κ +0.09~+0.21，
  区间含 0）——本集不含人类偏好判定，不更新该轴。
- **样本独立性**：90+90 题落在 95 个源段上；段级置换 p=0.0000 已按段聚类校正，
  但任何「180 个独立样本」的表述都是错的。
