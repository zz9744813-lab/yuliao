## 2. 只读统计入口（对账「82 条需复审」）

函数（位于 `app/knowledge_extract.py`，**只读 SELECT，不写库、不改 status**）：

```python
def review_ledger_stats(session) -> dict:
    """strategy_instances 复审进度对账。"""
    q = session.query(StrategyInstance)
    n_total = q.count()
    n_reviewed_new_def = q.filter(
        StrategyInstance.reviewer_version == REVIEW_MARKER_NEW_DEF).count()
    n_legacy = q.filter(or_(
        StrategyInstance.reviewer_version.is_(None),
        StrategyInstance.reviewer_version == "")).count()
    return {"n_total": n_total,
            "n_reviewed_new_def": n_reviewed_new_def,
            "n_legacy": n_legacy}
```

调用口径（对生产 session 即可，本交付测试用独立内存库，绝不碰真库）：

```python
from app import knowledge_extract as KE

    print(KE.review_ledger_stats(s))
# -> {'n_total': <总数>, 'n_reviewed_new_def': <新口径已复审>, 'n_legacy': <待复审>}
```

`n_legacy` 即审计 P1「82 条需复审」的进度对账口径：每按新口径复审一条并把
`reviewer_version` 置 `k2def-v1`，`n_legacy` 减 1、`n_reviewed_new_def` 加 1。
