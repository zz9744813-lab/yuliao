## 3. 主控修的三处测试缺陷（原交付在本机 3 failed）

原交付的 `tests/test_k4_registered_world_preflight.py` 在主控本机跑出
**3 failed / 25 passed**，根因均非「沙箱不能跑」，而是测试自身缺陷：

| # | 症状 | 真因 | 修法 |
|---|---|---|---|
| 1 | `NameError: name 'StrategyCondition' is not defined` | 导入清单漏 `StrategyCondition`（`app/models.py:492` 确有该类） | 导入补上 |
| 2 | `assert pre["registered"] is True` → False | `db.session()` **每次新开 Session**；测试只 `flush()` 未 `commit()` ⇒ 登记行对新会话不可见，`registered` 恒 False（**假红/假绿**：测的其实只是「未登记」路径） | 三处补 `s.commit()` |
| 3 | `IntegrityError: INSERT INTO works ... 'WK-REG'` | 同文件多测共享一个测试库，`WK-REG` 重复 INSERT（顺序依赖） | `_register_world` 幂等化（存在即复用/更新登记行） |

修后主控实跑：

```

    tests/test_k4_registered_world_preflight.py tests/test_k4_paired.py -q -o addopts=
```
